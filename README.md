# Sharodshava — Kolkata Durga Puja Interactive Guide & Planner

An immersive, high-performance web application celebrating Kolkata Durga Puja with interactive pandal maps, day-by-day ritual guides, cultural timelines, and authentic food trails.

## Features
- **Interactive Pandal Navigation:** Explore North, South, and Central Kolkata pandals with interactive zoning.
- **Festival Calendar & Timelines:** Detailed day-by-day guide from Maha Shashthi to Vijaya Dashami with ritual significances and auspicious moments.
- **Pujo AI Companion:** Grounded local assistance for finding nearby pandals, metro schedules, and street food.
- **Custom Squad Trip Planner:** Build custom pandal-hopping routes with friends.
- **Virtual Pushpanjali & Audio:** Experience the spiritual ambiance with ceremonial soundscapes.

## Tech Stack
- **Framework:** React 19, TypeScript, Vite 8
- **Styling:** Tailwind CSS, Framer Motion
- **Icons & Effects:** Lucide React, Canvas Confetti
- **Audio & Spatial Data:** Haversine distance computations & local transit guides

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
